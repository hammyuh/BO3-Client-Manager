Black Ops III Client Manager

BO3 CM

A launcher and client manager built for Call of Duty: Black Ops III. Switch between BO3 clients without manually moving files around.

Features

  • Client switching
  • Automatic BO3 installation detection
  • Client file management
  • Multiple profile support
  • Portable setup management

Supported Clients

  • Stock BO3
  • T7 Patch
  • BOIII Community
  • T7x
  • CleanOps T7
  • Ezz BOIII

About BO3 CM

BO3 CM keeps different Call of Duty: Black Ops III setups organized in one place. Built with C#, WPF, and .NET, it simplifies switching between different BO3 clients.
